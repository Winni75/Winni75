## 🤖 Current Practical Project

### NADOO Robotics – Autonomous Waste Collection Robot

I am currently working on a practical robotics project focused on developing an autonomous waste collection robot.

The project combines mechanics, electronics, and software development. It serves as a practical foundation for systematically deepening my knowledge of embedded systems and robotics.

The project includes, among other things:

* a 4WD driving platform controlled by an ESP32
* a 3D-printed robotic arm with servo control
* camera and image processing on a Jetson Nano
* Linux-based development environments
* future object detection with YOLO
* planned ROS 2 integration
* structured documentation using GitHub
